# 2026-09-12 対応形式の実装

P3（対応形式の拡張）の1件目と2件目。形式判定・プレーンテキスト・ソースコード・CSV/TSV。

## やったこと

- `src/format.rs`を新設。`Format`（markdown / code / csv / tsv / text）を拡張子で判定する。`md`系はマークダウン、`csv`/`tsv`はそれぞれ、`txt`と拡張子なしはテキスト、それ以外はハイライターがその拡張子を知っていればコード、知らなければテキスト。`FromStr`を持たせ、clapの`--format`でそのまま受ける。
- プレーンテキストは空行で段落を分け、段落内の改行は保ったまま幅で折り返す。
- ソースコードはファイル全体を1つのコードブロックにし、拡張子を言語名として渡す（syntectは`rs`のような拡張子表記も解決する）。JSON・YAML・TOMLもこの経路。
- CSV/TSVは`csv`クレートで読み、1行目を見出しにした表にする。列数が足りない行は空セルで埋め、セル内の改行は空白にする。空ファイルと読み取り失敗は1行の段落で知らせる。
- `Highlighter::supports()`を追加（拡張子を知っているか）。
- ファイルの読み込みを`read()`にまとめ、UTF-8でない時は「他の文字コードには未対応」と出す。
- `folio view`と`folio render`の両方に`--format`を追加。
- テスト5件。

## 確認したこと

`src/main.rs`が色付きで出ること、引用符・セル内改行・列数の足りない行を含むCSVが表として崩れないこと、拡張子なしのファイルが幅12で折り返されること、`--format text`でJSONが素のまま出ること、既定ではJSONに色が付くこと、`--format pdf`がclapのエラーになること。
