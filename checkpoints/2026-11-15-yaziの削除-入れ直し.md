# 2026-11-15 yaziの削除と入れ直し

## 経緯
- `fb`が動かないとの相談。`fb`関数は`~/.zshrc`に残っていたが、呼び先の`~/.cargo/bin/folio`が無かった。`~/.cargo/bin`が当日14:18に作り直されており（Rustの入れ直しなどとみられる）、`cargo install`で入れたものが一緒に消えていた。
- `cargo install --path .`で入れ直し、`folio --version`が0.3.0を返すことを確認。
- 設定ファイル`~/.config/folio/config.toml`も無かったので、2026-09-26の記録どおり`[browse] show_hidden = true`で作り直した。
- 同時に`~/.config/yazi`とyazi本体、練習の履歴`~/.local/share/folio`も無かった。yaziはユーザーが意図して削除したもの（`fb`で足りるようになったため）。

## 記録の変更
- AGENTS.mdの「それまでyaziは併用」を、削除済みに改めた。
- REQUIREMENTS.mdのP7（コピー・移動とyaziの置き換え）の「yaziの設定は残す」決定を、削除済みの決定に置き換えた。yaziから呼ぶ使い方は機能として残す（README・`folio render`は変えない）。
- PROGRESS.mdの現在地と次の一手から「yaziを開きたくなった場面」を「`fb`で困った場面」に改めた。

## 学び
- `~/.cargo`ごと作り直すと、`cargo install`で入れた`folio`も消える。`fb`が「command not found: folio」になったら`cargo install --path .`で戻る。
